# 🏠 Комната персонажа - Дизайн и Интерфейс

## Общее описание

**Комната персонажа** - это персональное пространство в таверне, где игрок может:
- 📦 Управлять инвентарём (предметы, добыча)
- ⚔️ Подготавливать боевые колоды (разложить карты)
- 🛠️ Использовать сундуки для хранения
- 🪑 Экипироваться (надевать броню, оружие)

## Кнопки и действия

### Основные кнопки

| Кнопка | Где расположена | Действие | Горячая клавиша |
|--------|-----------------|----------|-----------------|
| **Открыть комнату** | Таверна (в зоне "Комната отдыха") | Войти в комнату | `R` |
| **Вернуться** | Комната (вверху) | Вернуться в таверну | `ESC` или кнопка |
| **Надеть предмет** | Инвентарь/Экипировка | Надеть/снять | `E` |
| **Использовать предмет** | Инвентарь | Применить (зелье, свиток) | `U` |
| **Продать** | Инвентарь | Продать в лавку | `S` |
| **Выбросить** | Инвентарь | Удалить предмет | `DEL` |
| **Перенести** | Сундук → Рюкзак | Переместить вещь | `T` |
| **Разложить в колоде** | Инвентарь | Добавить карту в колоду | `D` |

### Контекстные меню (клик правой кнопкой)

```
На предмете:
├─ 📝 Информация
├─ ⚔️ Надеть
├─ 🔄 Перенести в сундук
├─ 💰 Продать
└─ 🗑️ Выбросить

На карте в сундуке:
├─ 📝 Просмотр
├─ 🃏 Добавить в колоду
├─ 🔄 Перенести в рюкзак
└─ 🗑️ Выбросить
```

### Файловая структура

```
scenes/
├── town/
│   └── character_room.py          # Сцена комнаты персонажа
│
ui/
├── character_room/
│   ├── __init__.py
│   ├── inventory_panel.py         # Панель инвентаря
│   ├── equipment_panel.py         # Панель экипировки
│   ├── storage_panel.py           # Панель сундуков
│   ├── deck_builder.py            # Построитель колод
│   └── info_panel.py              # Информационная панель
│
server/
└── items/
    ├── item_database.py           # БД предметов
    ├── inventory_manager.py       # Управление инвентарём
    └── equipment_system.py        # Система экипировки
```

### Структура данных

```python
# Предмет в инвентаре
class InventoryItem:
    item_id: int                    # ID предмета
    name: str                       # "Зелье маны"
    item_type: str                  # "potion", "material", "card"
    quantity: int                   # Количество (1-999)
    rarity: str                     # "common", "rare", "epic"
    weight: float                   # kg (0.1)
    price: int                      # Цена продажи (150)
    description: str                # "Восстанавливает 50 маны"
    effects: Dict[str, int]         # {"mana": 50}
    can_use: bool                   # Можно ли использовать
    
# Экипировка персонажа
class Equipment:
    slot: str                       # "head", "body", "weapon_main"
    item_id: int                    # ID предмета
    bonuses: Dict[str, int]         # {"+2 Сила": 2, "+1 HP": 1}
```

## Интеграция с боевой системой

Когда персонаж входит в бой:
1. Система читает текущую **активную колоду**
2. Берёт **базовые статы персонажа** + **бонусы от экипировки**
3. Применяет **эффекты экипировки** к боевым статам
4. Может ли персонаж использовать **зелья из рюкзака** во время боя?
