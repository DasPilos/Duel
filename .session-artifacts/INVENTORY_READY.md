- Скролл по колесу мыши
- Выбор предметов

- Отображение 10 слотов экипировки

#### StoragePanel (7.7KB)
- Отображение 2 сундуков
- Сетка 5×N для каждого сундука
- Вкладки переключения между сундуками
- Счётчик заполнения
- Скролл по колесу мыши

#### DecksPanel (5.5KB)
- Список всех боевых колод
- Статус активности (⭐ или ⚪)
- Информация о картах в каждой колоде
- Кнопки: Редактировать, Удалить, Активировать
- Показываем типы и количество карт

## 🔗 Как интегрировать в игру

### 1. Добавить кнопку в таверну:

```python
# tavern_scene.py
self.room_button = pygame.Rect(30, 850, 150, 55)  # Левый нижний угол

# В обработке событий:
if self.room_button.collidepoint(event.pos):
    self.navigate = "character_room"
```

### 2. Добавить в главный цикл:

```python
# main.py или дальше в обработке сцен
from scenes.town.character_room import CharacterRoom

if current_scene_name == "character_room":
    if not character_room:
        character_room = CharacterRoom(session)
    
    character_room.handle_event(event)
    character_room.update(dt)
    character_room.draw(screen)
    
    if character_room.finished:
        current_scene_name = "tavern"
```

### 3. Инициализировать БД в сервере:

```python
# server/main.py или инициализация
from server.items_database import ItemsDatabase

items_db = ItemsDatabase(database)

# Теперь доступны все методы:
items_db.add_to_inventory(character_id, item_id, quantity)
items_db.get_inventory(character_id)
items_db.equip_item(character_id, slot, item_id)
# и так далее...
```
