# Тестирование

## Быстрый запуск

Из корня проекта выполните:

```powershell
python -m unittest discover -s tests -v
```

Тесты не требуют открытия окна Pygame и проверяют боевую логику отдельно.

## Что проверяется

- регистрацию и вход пользователя через сервер;
- создание, сохранение и загрузку персонажа через API;
- сохранение состояния при отключении клиента.
- постоянную историю сообщений в SQLite;
- unread/read marker;
- серверный rate limit сообщений;
- дедупликацию сообщений в `ChatState`.

## Ручная проверка интерфейса

Запустите игру:

```powershell
python main.py
```

Проверьте экран распределения характеристик, выбор зон, комментарии, всплывающий урон и финальную статистику.
