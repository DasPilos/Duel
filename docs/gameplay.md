# Gameplay

## 1. Общая информация

Игра представляет собой пошаговый бой между игроком и противником.

В каждом ходу игрок выбирает:

- одну зону атаки;
- две разные зоны защиты.

Противник выбирает зоны автоматически. После выбора зон выполняется расчёт атак, обновляются здоровье и статистика, а результат добавляется в историю боя.

---

## 2. Боец

Боец создаётся с именем и уровнем. По умолчанию уровень равен `1`.

Начальные значения:

- каждая характеристика: `5`;
- свободные очки характеристик: `6`;
- мана: `50 / 50`;
- опыт: `0`.

При включённом автоматическом распределении свободные очки случайно распределяются между характеристиками.

### Характеристики

| Ключ | Название | Влияние |
|---|---|---|
| `strength` | Сила | Увеличивает физический урон |
| `agility` | Ловкость | Влияет на шанс уклонения |
| `intuition` | Интуиция | Влияет на шанс критического удара |
| `endurance` | Выносливость | Увеличивает максимальное здоровье |

---

## 3. Производные параметры

### Максимальное здоровье

Максимальное здоровье рассчитывается по формуле:

ext
max_hp = 100 + 20 × (level - 1) + endurance × 14


 Copy code


После создания здоровье полностью восстанавливается.

### Атака

ext
attack = 18 + 3 × (level - 1)


 Copy code


### Защита

ext
defense = 8 + 2 × (level - 1)


 Copy code


---

## 4. Распределение характеристик

Для увеличения характеристики используется одно свободное очко.

Уменьшать характеристику можно только до значения `4`. Ниже этого значения характеристика не опускается.

После изменения характеристик параметры бойца пересчитываются.

### Увеличение выносливости

При увеличении выносливости максимальное здоровье возрастает, а текущее здоровье увеличивается на размер прироста максимального здоровья.

### Уменьшение выносливости

Если после уменьшения характеристики максимальное здоровье стало ниже текущего, текущее здоровье ограничивается новым максимумом.

### Готовность бойца

Боец считается готовым к бою, если все свободные очки характеристик распределены:

ext
stat_points == 0


 Copy code


---

## 5. Опыт и повышение уровня

За победу над противником игрок получает `30 XP`.

Для повышения уровня требуется `60 XP`.

При повышении уровня:

- опыт уменьшается на `60`;
- уровень увеличивается на `1`;
- добавляется `6` свободных очков характеристик;
- пересчитываются производные параметры;
- здоровье полностью восстанавливается.

Если накоплено достаточно опыта для нескольких уровней, повышение выполняется несколько раз подряд.

---

## 6. Зоны атаки и защиты

В бою доступны следующие зоны:

| Ключ | Название |
|---|---|
| `head` | Голова |
| `body` | Туловище |
| `waist` | Пояс |
| `thigh` | Бедро |
| `shin` | Голень |

Игрок выбирает одну зону атаки и ровно две разные зоны защиты.

Некорректными считаются:

- неизвестная зона;
- отсутствие зоны атаки;
- количество зон защиты, отличное от двух;
- повторение зоны защиты.

Противник случайно выбирает одну зону атаки и две разные зоны защиты.

---

## 7. Порядок хода

Ход выполняется следующим образом:

1. Проверяется, завершён ли бой.
2. Увеличивается номер текущего хода.
3. Противник выбирает зоны атаки и защиты.
4. Определяется, заблокирована ли атака игрока.
5. Определяется, заблокирована ли атака противника.
6. Рассчитываются обе атаки.
7. Обновляется статистика бойцов.
8. Урон игрока наносится противнику.
9. Если противник выжил, ответный урон наносится игроку.
10. При победе игрок получает опыт.
11. Результат хода добавляется в историю.
12. Выбор зон игрока сбрасывается.

Если противник погиб от атаки игрока, ответная атака противника не наносит урон игроку.

---

## 8. Расчёт уклонения

Уворот полностью отменяет атаку и наносит `0` урона.

Шанс уклонения рассчитывается так:

ext
chance = defender.agility × 4
       - attacker.agility × 3
       - attacker.endurance


 Copy code


Итоговый шанс ограничивается диапазоном от `0%` до `95%`.

---

## 9. Расчёт базового урона

Для атаки бросаются две шестигранные кости.

Базовый урон рассчитывается по формуле:

ext
base_damage = max(
    1,
    attacker.attack
    + attacker.strength × 0.5
    - defender.defense
    - defender.strength × 0.5
    + сумма 2d6
)


 Copy code


Минимальный базовый урон равен `1`.

---

## 10. Блокировка

Атака считается заблокированной, если зона атаки нападающего совпала с одной из двух зон защиты противника.

### Обычная заблокированная атака

Обычная атака полностью блокируется:

- урон равен `0`;
- попадание не засчитывается;
- текущая серия сбрасывается.

### Критическая атака по блоку

Критическая атака пробивает блок частично.

При этом итоговый критический урон уменьшается в два раза:

ext
damage = ceil(damage / 2)


 Copy code


Такая атака наносит урон и продолжает серию.

---

## 11. Критические удары

Шанс критического удара рассчитывается по формуле:

ext
chance = attacker.intuition × 5
       - defender.intuition × 3


 Copy code


Каждое очко Интуиции атакующего даёт `5` процентных пунктов к шансу
критического удара. Каждое очко Интуиции защитника снижает этот шанс на `3`
процентных пункта как антикрит. Итоговый шанс ограничивается диапазоном от
`0%` до `95%`.

Для критического удара дополнительно бросается специальный множитель `d8`.

Возможные множители:

- `1.5` — 2 из 8 вариантов;
- `2` — 4 из 8 вариантов;
- `3` — 1 из 8 вариантов;
- `4` — 1 из 8 вариантов.

Критический урон рассчитывается так:

ext
damage = ceil обычный_урон × критический_множитель


 Copy code


Пятый результативный удар серии всегда является критическим, независимо от обычного шанса.

---

## 12. Комбо и серии ударов

Серия увеличивается только после результативного попадания.

Множители серии:

| Уровень серии | Множитель |
|---:|---:|
| 1 | `1.0` |
| 2 | `1.2` |
| 3 | `1.5` |
| 4 | `2.0` |
| 5 и выше | `2.0` |

После пятого результативного попадания:

- удар получает гарантированный критический эффект;
- текущая серия сбрасывается для следующего хода.

Серию также сбрасывают:

- успешный уворот защитника;
- обычная полностью заблокированная атака.

---

## 13. Урон и здоровье

Полученный урон округляется вниз до целого числа при обычном расчёте и вверх при применении критического множителя или делении урона при блоке.

При получении урона:

ext
hp = max(0, hp - damage)


 Copy code


Боец считается погибшим, если:

ext
hp <= 0


 Copy code


---

## 14. Завершение боя

Бой завершается, если погиб игрок или противник.

Возможные результаты:

- погиб только противник — победа игрока;
- погиб только игрок — победа противника;
- погибли оба — ничья.

---

## 15. Статистика боя

Для каждого бойца сохраняются:

- `hits` — количество результативных попаданий;
- `damage` — общий нанесённый урон;
- `critical` — количество критических ударов;
- `dodges` — количество успешных уклонений бойца от атак;
- `blocks` — количество атак, заблокированных бойцом;
- `combo_sessions` — количество начатых серий;
- `current_combo` — текущий уровень серии;
- `max_combo` — максимальный достигнутый уровень серии.

Серия считается начатой при достижении второго результативного попадания.

---

## 16. История боя

После каждого хода в историю добавляются:

- номер хода;
- зона атаки игрока;
- зоны защиты игрока;
- зона атаки противника;
- зоны защиты противника;
- нанесённый урон обеих атак;
- факт уклонения;
- уровень комбо;
- факт критического удара.

В истории хранятся только последние четыре хода. При добавлении новой записи самая старая удаляется.

---

## 17. Данные последней атаки

Для интерфейса и комментатора отдельно сохраняются результаты последней атаки игрока и противника:

- выбранная зона атаки;
- факт попадания;
- нанесённый урон;
- результаты броска `2d6`;
- факт критического удара;
- результат критического броска;
- критический множитель;
- факт уклонения;
- уровень комбо.
