# Deck: отдельный карточный режим

Код карточного режима находится в `deck/` и запускается через общий Pygame-клиент. Центральный сервер отвечает за аккаунты и лобби; каждый мир Deck обслуживает отдельный процесс `deck.server.main`.

## Как соединены компоненты

- `main.py` передаёт выбранный мир в `deck.entry.open_world`.
- Лобби получает адрес выделенного сервера мира из `worlds.server_url`.
- API Deck не монтируется в Tower или Economy runtime.
- Общие учётные записи, сессии и список миров остаются в схеме PostgreSQL `public`. Игровые таблицы Deck создаются миграциями в отдельной схеме `deck`.
- Серверный процесс Deck запускается только для мира с `mode='deck'` и кодом с префиксом `deck`.
- Пароль проверяется только на центральном сервере; центральный сервер выдаёт выбранному миру ограниченную сессию.

При обновлении центральный сервер применяет миграцию `0079_deck_mode_rename`: она переводит старый ключ режима и коды миров на `deck`, а PostgreSQL-схему переименовывает в `deck`, сохраняя игровые данные.

## Подготовка мира

У мира Deck должен быть уникальный ID, код с префиксом `deck` и режим `deck`. Создайте запись в общей таблице `worlds` один раз, выбрав свободный ID:

```sql
INSERT INTO public.worlds (id, code, name, status, created_at, mode)
VALUES (5, 'deck1', 'Deck', 'open', extract(epoch FROM now()), 'deck');
```

Не выполняйте пример, если ID `5` уже занят: сначала выберите свободный ID. Сервер не создаёт и не изменяет записи миров автоматически.

## Запуск

В PowerShell из корня репозитория задайте ID существующей записи Deck и запустите сервер мира:

```powershell
$env:HOST = '127.0.0.1'
$env:DECK_WORLD_ID = '5'
$env:DECK_PORT = '8800'
python -m deck.server.main
```

Миры обычно создаются и запускаются из центрального лобби; вручную запускайте их только для локальной отладки. Задайте адрес мира в `DECK_PUBLIC_URL`, если сервер доступен клиентам по другому адресу.

Запустите клиент через основной сервер:

```powershell
python main.py --online --server http://127.0.0.1:8765
```

Выберите Deck в лобби; клиент откроет карточный модуль по ответу `/api/deck/info`. Обычные миры продолжают открываться своими игровыми сценами.

## Проверки

```powershell
$env:SDL_VIDEODRIVER = 'dummy'
$env:SDL_AUDIODRIVER = 'dummy'
$env:PYTHONIOENCODING = 'utf-8'
python -m unittest discover -s tests/deck -t . -q
```

Тесты Deck используют временные схемы PostgreSQL. Для тестовой базы задайте `TEST_DATABASE_URL`; не направляйте его на производственные данные.
