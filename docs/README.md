# Мини-дуэль (game)

Небольшая пошаговая боевая игра на Pygame: игрок и противник поочерёдно выбирают зоны атаки и защиты, урон рассчитывается с учётом брони, серий попаданий и случайного множителя.

## Быстрый старт

```powershell
python main.py
```


## Требования

- Python 3.13+
- pygame 2.6.1+
- сервер использует только стандартную библиотеку Python

## Основные модули

### `client/`

HTTP-клиент, авторизация, сетевые сессии, сохранение персонажа, чат,
realtime-события и локальное состояние клиента.

### `server/`

HTTP API, SQLite-хранилище, пользователи и персонажи, чат и модерация,
присутствие игроков, заявки на дуэли, групповые бои, состояние ботов,
планировщик ботов и WebSocket-шлюз.

### `ui/chat/`

Общий и личный чат, список участников локации, история сообщений,
отправка сообщений, заявки и открытие профиля персонажа.

### `combat/`

Единый активный движок боя:

- `battle.py` — состояние боя, ходы, исход и XP;
- `fighter.py` — характеристики, HP, MP и уровень;
- `mechanics.py` — шансы крита и уклонения;
- `resolver.py` — расчёт отдельной атаки;
- `progression.py` — XP и повышение уровня;
- `group_battle.py` — правила группового боя;
- `anticheat.py` — аудит подозрительных матчей;
- `battle_archive.py` — архив завершённых боёв;
- `zones.py` — зоны атаки и защиты.

### `scenes/`

Экран авторизации, выбор персонажа, таверна, задний двор и дуэль.
Дополнительные модули отвечают за ввод, тайминги боя и комментарии.

### `ui/`

Pygame-интерфейс, карточки персонажей, рендеринг дуэли, HUD, чат,
профили и элементы выбора атаки и защиты.

Старого пакета `ui/combat/` больше нет.

## Глоссарий UI

- **Карточка персонажа** — это единый UI-блок просмотра персонажа,
  который открывается по правому клику на ник в чате, а также при просмотре
  заявок на поединок. Карточка содержит: ник, уровень, HP/MP, спрайт,
  характеристики и кнопку закрытия.
- Все будущие действия (`запросить обмен`, `пожаловаться`, `добавить в друзья`,
  `пригласить в клан`, `передать предмет`) добавляются именно в эту карточку,
  а не в отдельные всплывающие окна.

## Ключевые принципы проекта

- `combat/*` не импортирует Pygame и не знает об интерфейсе.
- `ui/*` отвечает только за отрисовку, не принимает решений о правилах боя.
- `scenes/duel_scene.py` — единственный слой, связывающий `combat` и `ui`.
- `main.py` не содержит игровой логики.

## Локальный сервер

Сервер запускается отдельно командой `python -m server.main`.
Инструкция по API и CLI-клиенту находится в [`server.md`](server.md).
