# Мини-дуэль (game)

Небольшая пошаговая боевая игра на Pygame: игрок и противник поочерёдно выбирают зоны атаки и защиты, урон рассчитывается с учётом брони, серий попаданий и случайного множителя.

## Быстрый старт

powershell
python main.py


## Требования

- Python 3.13+
- pygame 2.6.1+

## Ключевые принципы проекта

- `combat/*` не импортирует Pygame и не знает об интерфейсе.
- `ui/*` отвечает только за отрисовку, не принимает решений о правилах боя.
- `scenes/duel_scene.py` — единственный слой, связывающий `combat` и `ui`.
- `main.py` не содержит игровой логики.

## Известные пробелы в документации

Следующие файлы существуют в проекте, но их содержимое ещё не задокументировано подробно и требует уточнения при следующей ревизии:

- `main.py` (полный листинг)
- `core/settings.py` (полный список констант)
- `combat/zones.py` (полное содержимое словаря `ZONES`)
- `combat/comments.py` (полное содержимое `ATTACK_COMMENTS` / `DEFENSE_COMMENTS`)
- `ui/hud.py` (полные реализации функций)
- `ui/sprite_loader.py` (класс `FighterSprite`)
