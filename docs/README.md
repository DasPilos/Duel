# Мини-дуэль (game)

Небольшая пошаговая боевая игра на Pygame: игрок и противник поочерёдно выбирают зоны атаки и защиты, урон рассчитывается с учётом брони, серий попаданий и случайного множителя.

## Быстрый старт

```powershell
python main.py
```


## Требования

- Python 3.13+
- pygame 2.6.1+
- сервер использует только стандартную библиотеку Python

## Глоссарий UI

- **Карточка персонажа** — это единый UI-блок просмотра персонажа,
  который открывается по правому клику на ник в чате, а также при просмотре
  заявок на поединок. Карточка содержит: ник, уровень, HP/MP, спрайт,
  характеристики и кнопку закрытия.
- Все будущие действия (`запросить обмен`, `пожаловаться`, `добавить в друзья`,
  `пригласить в клан`, `передать предмет`) добавляются именно в эту карточку,
  а не в отдельные всплывающие окна.

## Ключевые принципы проекта

- `combat/*` не импортирует Pygame и не знает об интерфейсе.
- `ui/*` отвечает только за отрисовку, не принимает решений о правилах боя.
- `scenes/duel_scene.py` — единственный слой, связывающий `combat` и `ui`.
- `main.py` не содержит игровой логики.

## Локальный сервер

Сервер запускается отдельно командой `python -m server.main`.
Инструкция по API и CLI-клиенту находится в [`server.md`](server.md).
