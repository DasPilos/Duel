# Известные ограничения

- Игровые данные хранятся только на сервере; клиент работает через HTTP (`--online`).
- WebSocket-чат — опциональный отдельный процесс; без него используется HTTP.
- Бой на карте мира — против мобов (`scenes/world_map_scene.py`).
- Магия на карте мира не реализована: формула магического урона есть, атак нет.
- Маг: характеристики и формулы — временная заглушка.
- Состояние боя не сохраняется между запусками.
- Интерфейс рассчитан на 1920×1080, адаптивности нет.
- `scenes/world_map_scene.py` очень большой (около 2700 строк) и требует разбиения.
- Мониторинг использует Linux `/proc` и systemd; на Windows работает только импорт и тесты разбора данных.
- Один сервер обслуживает один мир (`WORLD_ID`).
