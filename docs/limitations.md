# Известные ограничения

- Сервер и клиентский сетевой слой пока работают только локально.
- Состояние боя не сохраняется между запусками.
- Серверная SQLite-база хранит пользователей, сессии и персонажей.
- Сетевой бой ещё не подключён к Pygame-сцене.
- Противник выбирает зоны случайно.
- Размер окна и расположение интерфейса рассчитаны прежде всего на 1920x1080.
- Случайные броски не имеют отдельного источника случайности, поэтому воспроизведение конкретного боя затруднено.
- Один пользователь может иметь несколько персонажей.
- WebSocket-шлюз запускается отдельно, а Pygame использует HTTP fallback.
- Мобильная адаптивность не реализована для desktop Pygame-клиента.
- UI модератора пока представлен серверными API без отдельной панели.
