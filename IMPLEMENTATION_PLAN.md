### **Этап 2: Система уникальных ресурсов (PRIORITY 1)**
Реализовать ярость, меткость, концентрацию в боевой системе.

**Файлы для изменения:**
- `combat/fighter.py` - добавить поле `unique_resource` и его управление
- `combat/card_battle.py` - добавить логику для применения карт через уникальные ресурсы

**Логика ярости (Rage):**
```python
# При получении урона
if damage_taken >= 10:
    rage += 10 + (2 * level)

# В конце хода
rage += 4 (восстановление)

# При применении карты
if card.resource_cost > 0:
    rage -= card.resource_cost
```

**Логика меткости (Accuracy):**
```python
# При уворотах
accuracy += 7 + (1 * level)

# В конце хода
accuracy += 5 (восстановление)
```

**Логика концентрации (Concentration):**
```python
# При крит ударах
concentration += 15 + (1 * level)

# В конце хода
concentration += 9 (восстановление)
```

### **Этап 4: Система элементов и реакций (PRIORITY 2)**

#### **4.1 Новые статусы**
- **Яд (Poison)** - 3% HP за ход, +10% крит шанса к врагу, может стакаться, снимается в конце хода
- **Кровотечение (Bleed)** - накапливается до 100%, при 100% наносит 30% HP
- **Духовный урон (Spiritual Damage)** - 65% физ, 35% духовный, счисляется на отдельный пул HP
- **Ослепление (Blinding)** - +20% промоха на 1 ход
- **Стойка (Stance)** - не может использовать карты, можно прервать станом
- **Охота (Hunt)** - не может использовать карты, можно прервать станом
- **Прочтение (Channeling)** - не может использовать карты, можно прервать станом

#### **4.2 Реакции элементов (7 типов)**
```
Огонь + Вода:        × 0.5 урона, снять оба статуса
Огонь + Холод:       × 0.2 урона, снять оба статуса
Огонь + Электро:     × (1.3 + гармония×1%) урона, ослепление на 1 ход, снять оба
Вода + Электро:      × (1.1 + гармония×1%) урона, 40% урона всем врагам, вода остается
Вода + Холод:        Заморозка на 1 ход (1 карта/ход), иммунитет 1 ход
Электро + Холод:     30% урона → щит, снять оба, иммунитет 1 ход
Воздух + любой:      Снять 1 ход статуса
```

#### **4.3 Постоянные статусы**
```
Огонь:       2 урона/ход, стекается до 1 после реакции
Вода:        -15% уворотов (не стекается)
Холод:       +20% входящий урон
Электро:     Стан после 3 ходов (не стекается)
```
