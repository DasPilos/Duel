# Функциональность удаления персонажа с подтверждением пароля

## Описание

Добавлена возможность удаления персонажа из экрана выбора персонажей с двухуровневой защитой от случайного удаления:

1. **Кнопка удаления** - Красная кнопка "УДАЛИТЬ ПЕРСОНАЖА" появляется под кнопкой "ПРОДОЛЖИТЬ ИГРУ" когда персонаж выбран
2. **Диалог подтверждения** - При нажатии на кнопку удаления появляется модальное окно с полем для ввода пароля
3. **Проверка пароля** - Пароль пользователя проверяется на сервере перед удалением
4. **Защита от случайного клика** - Полутрансспарентный черный фон блокирует взаимодействие с остальным интерфейсом

## Компоненты

### Клиент (client/)
- **`network.py`** - Добавлены методы для удаления персонажей:
  - `delete_character(character_id)` - удаление без пароля (для внутренних операций)
  - `delete_character_with_password(character_id, password)` - удаление с проверкой пароля

- **`session.py`** - Методы сессии:
  - `delete_character(character_id)`
  - `delete_character_with_password(character_id, password)`

### Сервер (server/)
- **`main.py`** - POST endpoint `/api/characters/{id}/delete`
  - Проверяет авторизацию пользователя
  - Если передан пароль - проверяет его корректность
  - Вызывает методы удаления в БД

- **`database.py`** - Методы БД:
  - `delete_character(user_id, character_id)` - базовое удаление с проверкой владения
  - `delete_character_with_password(user_id, character_id, password)` - удаление с проверкой пароля
  - `get_user(user_id)` - получение пользователя с хэшем пароля
  - `validate_character_name()` - исправлена декоратор `@staticmethod`

### Сцена (scenes/)
- **`character_scene.py`** - Интерфейс удаления:
  - Добавлена кнопка `delete_button` красного цвета
  - Добавлены элементы диалога подтверждения:
    - `show_delete_confirmation` - флаг показа диалога
    - `delete_password` - текущее значение пароля
    - `delete_error` - сообщение об ошибке
    - Поле ввода `password_input_rect`
    - Кнопки подтверждения и отмены
  - Метод `_confirm_delete()` - обработка подтверждения удаления
  - Обновлена `handle_event()` для обработки ввода в диалог
  - Обновлена `draw()` для отображения кнопки и диалога

## Сценарии использования

### 1. Удаление во время выбора профессии
```python
# ProfessionSelectScene может вызвать удаление для отмены
self.session.delete_character(self.character_id)  # без пароля
```

### 2. Удаление из списка персонажей
```
1. Пользователь выбирает персонажа в списке
2. Нажимает красную кнопку "УДАЛИТЬ ПЕРСОНАЖА"
3. Появляется диалог с запросом пароля
4. Вводит пароль и нажимает "УДАЛИТЬ" или "ОТМЕНИТЬ"
5. Если пароль верный - персонаж удаляется из БД и исчезает из списка
6. Если пароль неверный - показывается ошибка "Неверный пароль"
```

## Безопасность

- Пароль передается в теле POST запроса и проверяется на сервере
- Пароль отображается звездочками (*) в UI для конфиденциальности
- Используется метод `_check_password()` с PBKDF2-HMAC-SHA256 для сравнения
- На сервере проверяется владение персонажем до удаления

## Тестирование

Все сценарии протестированы:
- ✓ Удаление персонажа без пароля (профессия)
- ✓ Удаление персонажа с верным паролем
- ✓ Отказ в удалении с неверным паролем
- ✓ Персонаж остается в БД при неверном пароле
